```
You are producing a 3-minute cinematic narration script for a cybersecurity 
lunch-and-learn video. The audience is a customer's security and IT leadership 
team — non-technical executives and practitioners. The video plays before a 
live adversary simulation demonstration using Palo Alto Networks Cortex XDR 
and XSIAM.

Unlike the previous scenario, this attack is not slow or quiet. It is fast, 
deliberate, and devastating. The customer should finish the video feeling the 
weight of how quickly everything can be gone.

Using the narrative provided, write a 3-minute video script (approximately 
450 words of spoken narration) with the following structure:

SCENE 1 — THE MARKET (0:00–0:20)
Open not in the victim's office, but in the dark — a credential for sale, 
a buyer, a transaction. The breach begins before the attacker ever touches 
the network. Tone: transactional, cold, businesslike.

SCENE 2 — THE DOOR OPENS (0:20–0:45)
A single RDP connection. Valid credentials. The attacker is inside 
immediately — no phishing, no malware delivery, no waiting. They are 
simply... in. Tone: jarring, abrupt — the speed should feel wrong.

SCENE 3 — THE CHECKLIST (0:45–1:15)
The attacker moves through their routine — defenses disabled, network 
mapped, credentials harvested, spread to every machine in the environment. 
Narration should convey that this is practiced, mechanical, routine for 
the attacker. Forty-three minutes total. Tone: relentless, procedural.

SCENE 4 — BEFORE THE DETONATION (1:15–1:45)
Data is staged and exfiltrated before a single file is encrypted. The 
attacker already has what they came for. What comes next is not the 
primary objective — it is leverage. Tone: deliberate, ominous.

SCENE 5 — THE MOMENT (1:45–2:30)
Ransomware drops across every machine simultaneously. Files renamed. 
Recovery options destroyed. Passwords changed. The ransom note appears 
on every screen at once. Narration should convey the totality of the 
loss — not just files, but access, continuity, trust. Tone: stark, final.

SCENE 6 — THE MORNING AFTER (2:30–3:00)
An employee arrives at their desk. A black screen. White text. 
72 hours. Pull back — the attacker is already gone, already paid, 
already onto the next target. Close with the question: "In forty-three 
minutes, what could your team have seen?" Tone: quiet, heavy — 
the contrast with Scene 3's speed should land hard.

FORMAT REQUIREMENTS:
- Write narration as spoken words only — no bullet points, no headers 
  in the narration itself
- Include a [VISUAL CUE] note for each scene describing what should 
  appear on screen (abstract/cinematic, not literal screenshots)
- Keep language accessible — avoid acronyms, explain any technical 
  term in plain language the first time it appears
- Emphasize speed throughout — the entire operation takes less time 
  than a lunch break
- The final line should naturally hand off to the live demonstration
```
