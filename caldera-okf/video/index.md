# Video Prompts

NotebookLM prompts for generating 3-minute cinematic narration scripts for each operation. Videos are designed for customer lunch-and-learn sessions — played before the live Caldera simulation to set context, then followed by a Cortex XDR / XSIAM detection demonstration.

* [op1_silent_fog_prompt](op1_silent_fog_prompt.md) — Nation-state espionage (APT29). Tone: slow, patient, invisible.
* [op2_crimson_tide_prompt](op2_crimson_tide_prompt.md) — Ransomware campaign (Wizard Spider). Tone: fast, brutal, total loss.
* [op3_dark_pivot_prompt](op3_dark_pivot_prompt.md) — Supply chain compromise (APT10). Tone: quiet, trusted, already inside.

## Usage

1. Open NotebookLM and create a new notebook
2. Add the relevant operation file as a source (e.g. `op1_silent_fog.md`)
3. Paste the prompt from this folder into the NotebookLM prompt field
4. Generate — review and adjust pacing as needed for your delivery style
