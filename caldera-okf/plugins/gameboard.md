# Gameboard Plugin

The `gameboard` plugin provides a real-time red vs. blue monitoring dashboard for adversary emulation exercises. Shows agent activity, detections, and scoring as operations run.

**Source:** https://github.com/mitre/gameboard (commit d1ceb580b18a382ba05885664e241b10a2c2b584)
