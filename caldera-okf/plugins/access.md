# Access Plugin

The Access plugin provides initial access capabilities — techniques for getting the first agent onto a target host without assuming a pre-existing implant. It extends Caldera's reach from post-exploitation into the initial compromise phase.

- Phishing payload generation

- Credential spray and stuffing
